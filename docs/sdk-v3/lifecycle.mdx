# Lifecycle map

:::caution[v3 release candidate, unreleased]

<code>@obolnetwork/obol-sdk@{lifecycle.version}</code>. Names may still change before 3.0.0. For the released SDK see the [2.x reference](../sdk/index.md).

:::

A cluster's life, in the order it happens, with the operations for each stage. **prepare** operations return a transaction to [send](./reference/send.md); **sign** operations sign with the wallet and post to the Obol API; **check** operations verify untrusted input; ⚠ counts the warning codes a transaction can carry, which `send` asks you to [acknowledge](./warnings.md).

Some operations serve every stage: [`obol.send`](./reference/send.md#send) and the acknowledgement helpers, [`obol.experimental.simulate`](./reference/experimental.md#simulate), and the [standalone checks](./reference/checks.md) a server runs on what users send it.
